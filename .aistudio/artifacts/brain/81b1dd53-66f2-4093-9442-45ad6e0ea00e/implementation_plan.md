# WASMレンダリングのタイムアウト解消および促音（っ・ッ）最適化計画

C++ WebAssembly（vose_core.wasm）実行時のタイムアウトエラーを解消し、促音（「っ」「ッ」）ノートを無音休符として直後の子音へ自然に接続する音質・安定性改善の実施計画です。

## User Review & Critical Decisions

> [!IMPORTANT]
> ユーザー確認済みの基本方針に基づき、以下の2点を中心に実装します。

- **促音（っ・ッ）の挙動**: 促音休符（無音区間）として即座に識別・処理し、不要な音源フェッチやフォールバック警告を防止した上で、直後ノートの子音発声タイミング（先行発声・オーバーラップ）を自然に保ちます。
- **WASMコアのメモリ整合性**: C++側の `NoteEvent` 構造体（88バイト、`double`型メンバーのアライメントパディング考慮）とWorker側のバイナリ構築を完全に一致させ、不正メモリアクセスとハングアップ・タイムアウトを根絶します。

---

## 1. Overview & Core Concept

- **目的**: 
  1. `voseCoreWorker.ts` と `vose_core.wasm` の構造体メモリアライメントの完全一致により、C++コア合成が秒単位で高速・確実に完了するようにする。
  2. `wasmEngine.ts` および `voseCoreClient.ts` の休符判定（`REST_LYRICS_SET` / `isRest`）に促音（`っ`, `ッ`, `_っ`, `_ッ`）を追加し、不要なネットワーク通信（存在しない `っ.wav` の取得試行）と不要な未解決警告を解消する。
- **効果**:
  - レンダリング時に Web Audio オフラインエンジンへ不本意にフォールバックすることなく、本物の C++ WASM WORLD 合成エンジンが高品位かつ高速に動作。
  - 「Voice sample unresolved; skipping note lyric='っ'」などの13回にわたる警告ログと長時間の通信ウェイトがゼロになる。

---

## 2. User Experience & Visual Design

- **レンダリング進捗の向上**:
  - これまで「35%」で数十秒止まった末にタイムアウトしていた合成処理が、NoteEventのアライメント整合と促音の即時処理によってスムーズに進捗率（35% → 50% → 80% → 100%）を更新。
- **再生音質の改善**:
  - 促音「っ」の直後にある子音（「か」「た」「ぱ」等）が無音ブレイクを挟んで正確なアタックタイミングで発声され、歯切れの良い歌唱表現を実現。
- **エラーログのクリーン化**:
  - コンソールから13個の連続警告およびタイムアウト警告が消去され、明瞭なレンダリング完了通知のみが表示される。

## 3. Key Product Decisions & Trade-Offs

- **決定 1: NoteEvent構造体 stride=88 の完全保証**
  - *採用内容*: `voseCoreWorker.ts` において、`NOTE_EVENT_SIZE = 88` および各フィールドのメモリ配置（`double`型の8バイトアライメント、パディング4バイト、各ポインタのオフセット）を C++ `include/vose_core.h` と1バイトの狂いもなく同期させる。
  - *理由*: C++側が `notes[i]` を88バイト間隔でインデックス参照するため、JS側のメモリ書き込みと完全に一致していないと隣接ノートのポインタが破壊され、メモリセグメンテーションフォルトや無限ループ・ハングの原因となるため。
- **決定 2: 促音（っ・ッ）の即時無音化と先行発声保持**
  - *採用内容*: `REST_LYRICS_SET` に `っ`, `ッ`, `_っ`, `_ッ` を登録し、サンプル取得ループから除外する。ただし直後ノートとのタイミング計算においては促音の長さを無音間隔（Gap）として認識し、直後ノートの先行発声（Preutterance）が無音区間に正しく食い込む（自然なアタック）ように制御する。
  - *理由*: UTAU原音設定（oto.ini）や歌声合成の文脈において、促音は独立した母音波形ではなく無音のタメであるため、存在しないWAVの要求を未然に防ぎつつ、リズムタイミングを正確に保つ最善のアプローチであるため。

## 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────┐
│                   Main UI Thread                       │
│  (Piano Roll, Note Sequence, UST/Vocal Timeline)       │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│                  voseCoreClient.ts                     │
│  • isRest(): 'っ', 'ッ' を休符（無音）として即座に識別 │
│  • 無駄な 'っ.wav' のネットワークバッチ取得をスキップ  │
│  • タイムライン・先行発声マッピングを正確に計算         │
└───────────────────────────┬────────────────────────────┘
                            │ postMessage (notes, samples)
                            ▼
┌────────────────────────────────────────────────────────┐
│                  voseCoreWorker.ts                     │
│  • NOTE_EVENT_SIZE = 88 (sizeof(NoteEvent) = 88)       │
│  • 8-byte aligned: double intensity, modulation, etc.  │
│  • execute_render_cancelable() を安全・高速に呼び出し  │
└───────────────────────────┬────────────────────────────┘
                            │
                            ▼
┌────────────────────────────────────────────────────────┐
│                 vose_core.wasm (C++)                   │
│  • WORLD解析 / 合成が正常に完了 (クラッシュ/ハングなし)│
│  • /vose_output.wav を生成して完了通知                 │
└────────────────────────────────────────────────────────┘
```

### 修正対象ファイルと役割
1. `src/voseCoreClient.ts`:
   - `REST_LYRICS_SET` に `'っ'`, `'ッ'`, `'_っ'`, `'_ッ'` を追加。
   - `isRest()` の正規表現に促音パターンを網羅。
   - 促音ノートの直後におけるCVVC / VCV遷移および先行発声マッピングが正しく無音区間と連動するよう整理。
2. `src/wasmEngine.ts`:
   - 同様に `REST_LYRICS_SET` と `isRest()` に促音を追加し、フォールバック時にも「Voice sample unresolved; skipping note lyric='っ'」が出ないよう整合性を担保。
3. `src/voseCoreWorker.ts`:
   - `NOTE_EVENT_SIZE = 88` および `NoteEvent` 各オフセットの配置を検証・確認し、C++のメモリ仕様との完全整合を定着。
