# 音質改善計画書：吐息混入の解消と滑らかでハッキリした歌声の実現

## 1. ユーザー要望と課題の整理
- **主な不満点**:
  - 意図しない箇所で吐息（ブレスノイズ・かすれ音）が混入する。
  - 音と音の接続や声質が不安定で、ハッキリとした歌声になっていない。
- **選択された対応方針**:
  - **合成エンジンの補正**と**クロスフェード改善**の両方を包括的に実施。

---

## 2. 原因分析（根本原因）
1. **原音末尾（リリース呼気）の巻き込み・ループ混入**:
   - UTAU音源や生成音源のWAV末尾（右ブランク/Cutoff付近）には、声の抜き際や呼気（吐息）成分が含まれている場合が多くあります。
   - タイムマッピング（`map_time`）およびループ判定処理において、末尾のマージンが浅いと、持続母音の引き伸ばしやループ時にこの「吐息」が繰り返し再生・サンプリングされ、不自然なブレス音が発生していました。
2. **WORLDボコーダー / D4Cの非周期成分（Aperiodicity）によるホワイトノイズ化**:
   - WORLD合成において、ピッチシフト時や子音と母音の境界付近で非周期成分（`ar`）が高く評価されると、有声音であっても高周波の息漏れノイズ（ヒス・ザー音）が励起され、ロボット的な金属音や予期せぬ吐息音として聴こえていました。
3. **ノート接続部（クロスフェード）の段差とアタック時のクリック音**:
   - ノート同士が重ならない区間（`overlap_samples == 0`）で先頭のアタックフェードインが省略されていたため、波形段差によるポップノイズ（破裂的な息音に聞こえるクリック）が発生していました。
   - ノート間のクロスフェードが等パワー（Equal Power）化されておらず、音量低下や位相干渉による途切れ感（ブツ切り感）が生じていました。
4. **周波数特性（EQ・フィルター）のバランス**:
   - 9kHz以上のハイシェルフや不要な高域ブーストが、歌声の芯よりも吐息ノイズ成分を増幅させていました。一方で、子音の滑舌・発音の輪郭を決定づける帯域（3kHz〜4.5kHz）が十分に最適化されていませんでした。

---

## 3. 具体的な改修方針と計画

### ステップ1: 合成エンジンの非周期性制御とクリーン化（WASM/C++ コア `vose_core.cpp`）
- **有声母音区間の非周期成分（ar）の適正クランプ**:
  - 有声持続部において、D4Cが過大評価した高域ノイズを厳格に抑制。声帯振動の倍音成分（純粋な調波構造）をクリアに出力し、予期せぬ吐息音の発生を遮断。
  - 摩擦音・破裂音などの子音部（k, s, t, p, h等）のみ適度な高域非周期性を許容し、クリアでハッキリとした子音アタック（滑舌）を両立。
- **タイムマッピングの安全マージン拡大**:
  - `map_time` および `map_time_with_preutterance` において、Cutoff手前のセーフティマージンを拡大し、原音波形の抜き際（息吐き成分）が母音伸長に巻き込まれないよう保護。
- **ポストEQの刷新**:
  - 吐息ノイズをブーストしてしまう9kHz帯の余分な持ち上げをカット。
  - 箱鳴り・こもりを抑える350Hzのディマッド（De-mud）、および歌詞の発音をクッキリ際立たせる3.5kHz〜4kHzのプレゼンス補正を洗練。

### ステップ2: クロスフェードとエンベロープの刷新（C++ コア & `wasmEngine.ts` / `App.tsx`）
- **Equal-Power（等パワー特性）クロスフェードの導入**:
  - 音と音の接続部において、音量が落ち込まずエネルギーが均一に維持されるサイン・コサインまたはスクエアルート型等パワークロスフェードを適用。
- **アタック・リリースのマイクロフェード徹底**:
  - 先行ノートがない場合や休符明け（`overlap_samples == 0`）でも、最低限のマイクロフェード（3〜5ms）を必ず適用し、音の立ち上がりでのプチッという衝撃音・クリックノイズを完全防止。
- **母音ループ生成アルゴリズムの最適化**:
  - Web Audio / `wasmEngine.ts` において、長音ループ時に原音の末尾（吐息部）を完全に回避し、安定した母音区間の中央部分のみを位相連続・ゼロ交差点でシームレスに周回させる。

### ステップ3: サンプル解決とマスタリングフィルターの最適化（`server.js` & `App.tsx`）
- **不要なブレスサンプルの誤マッピング防止**:
  - 通常の歌詞・音素が誤って「息」や「br」などのブレスエイリアスにフォールバックしないよう、除外フィルタを強化。
- **リアルタイム再生 & オフライン出力のマスタリングチェイン統一**:
  - プレビュー再生（`App.tsx`）と書き出し（WAV Render）で音質差が出ないよう、高品位なボーカルチェイン（HPF 75Hz、De-Mud 350Hz、Articulation Boost 3.8kHz、高精度リミッター）を完全に統一。

## 4. 検証手順
1. **ビルド検証**:
   - `compile_applet` および `lint_applet` を実行し、構文エラー・型定義の整合性を確認。
2. **音質・接続の検証**:
   - 連続した音符（母音連続・子音＋母音）をレンダリングし、音と音の境界でプチプチ音や音量低下が発生しないことを確認。
   - ノートとノートの合間や持続音の終端で、予期せぬ吐息音やヒスノイズが混入せず、滑らかかつハッキリとしたボーカルになっているか確認。
