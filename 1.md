# VO-SE Web UI v2

## Responsive Wireframe Specification

## 1. Purpose

VO-SE Desktop の編集体験を基準として、Web UI を再設計する。

対象：

* Desktop Browser
* iPad / Tablet
* iPhone / Smartphone

基本原則：

> **同じ VO-SE を、画面サイズと入力方式に合わせて異なるレイアウトで操作する。**

機能・用語・操作モデルは統一し、レイアウトのみ Adaptive に変更する。

---

# 2. Screen Model

VO-SE のメイン画面は以下の領域から構成する。

```text
┌─────────────────────────────────────────────┐
│ App / Project / Transport Toolbar           │
├──────────┬───────────────────────┬──────────┤
│          │                       │          │
│ Track    │                       │ Inspector│
│ Panel    │      Piano Roll       │ /        │
│          │                       │ Parameter│
│          │                       │          │
├──────────┴───────────────────────┴──────────┤
│ Timeline                                    │
├─────────────────────────────────────────────┤
│ Transport / Status                          │
└─────────────────────────────────────────────┘
```

主要領域：

1. Top Toolbar
2. Track Panel
3. Piano Roll
4. Inspector / Parameter
5. Timeline
6. Transport
