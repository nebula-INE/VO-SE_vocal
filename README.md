
VO-SE vocal は、Python による高度なGUIと、C言語による高速な信号処理を組み合わせた、次世代ハイブリッド型音声合成プラットフォームです。

🚀 3つのコア・テクノロジー
1. ハイブリッド・パフォーマンス

ロジック制御と複雑な解析には柔軟な Python を、レイテンシが命となる音声信号処理には C言語 (C++20) を採用。 DLL/dylib 連携により、業界トップクラスの「動作の軽快さ」と「データ軽量化」を両立しました。


GitHub Actions による CI/CD パイプラインを構築。 Windows (.exe) だけでなく、macOS (.app) 環境やLinux系にも対応。アドホック署名を自動適用し、最新の Apple Silicon Mac でも動作可能なバイナリを提供します。





【Macユーザーの方へ】 開発者が中学生の為Apple Developer登録料（年間99ドル）の捻出が難しく、現在は「未認証（アドホック署名）」での配布となっています。初回起動時に警告が出ますが、ご了承お願いします。



📦 インストール
[release] から、OSに合ったファイルをダウンロード。

Windows: .exe を実行。

Mac: .zip を解凍し、アプリを 右クリック > 開く で実行。


Linux（Ubuntu / Linux Mint）:

- 推奨: `vo-se-vocal_amd64.deb` をダウンロードし、次のコマンドでインストールしてください。必要な Qt/XCB・音声ランタイム依存関係はパッケージマネージャーが解決します。
  
  ```bash
  sudo apt install ./vo-se-vocal_amd64.deb
  ```
- `VO-SE_vocal_Linux_x86_64.tar.gz` と単体の `VO-SE_vocal_Linux_x86_64` は、OSの共有ライブラリまで含む完全な自己完結型ではありません。依存ライブラリが不足している環境では起動しないため、通常は上記の Debian パッケージを使用してください。
